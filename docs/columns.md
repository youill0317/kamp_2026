# okm_augumented_2021.csv 컬럼 설명

공식 컬럼 정의 문서는 없다(KAMP 과제공개 hwpx, 데이터셋 zip, 웹 검색 모두 확인). 아래는 데이터에서 직접 검증한 내용이며, 추정인 부분은 **(추정)** 으로 표시했다.

- 기간: 2021-01-01 ~ 2021-09-14, 257일 × 24시간 = 6,168행 (1행 = 1시간)

- `날짜`: 날짜 (YYYYMMDD 정수)
- `시간`: 시(0~23)
- `15분` `30분` `45분` `60분`: 해당 시간의 15분 구간별 전력사용량 **(추정: 15분 평균 kW)**
- `평균`: 위 4개 값의 평균(반올림)
- `생산량`: 시간당 생산량 **(추정: 실적)**
- `기온`: 기온(℃)
- `풍속`: 풍속(m/s)
- `습도`: 습도(%)
- `강수량`: 강수량(mm)
- `전기요금(계절)`: 계절별 전력량 단가 **(추정: 원/kWh)**
- `day`: 요일
- `d`: 일(日)
- `m`: 월
- `공장인원`: **사람 수 아님.** `생산량 / (15분+30분+45분+60분)`
- `인건비`: 인건비 할증 배율

## 주의사항

- **누설(leakage)**: `평균`, `공장인원`은 당일 전력값으로 계산된다. 전력 예측 피처로 쓰면 안 된다.
- **사용자 확인(2026-10-03)**: 누수 지적 대상은 `공장인원`이며 분모가 타깃 전력 합이다. 생산량에 대한 누수 지적은 정정되었다. 생산량은 평가 시 제공 여부와 계획/실적 구분을 확인하여 조건부 입력으로 다룬다.
- **증강 복제일**: 257일 중 160일이 45개 그룹을 이루며, 그룹 안에서는 24시간×4칸 전력값이 완전히 같다(원본 외 복사본 115일). 같은 그룹이라도 기온은 모두 다르고, 생산량이 같은 그룹은 5개뿐이다. 즉 전력만 복사되어 복제일에는 생산량·기상과 전력이 서로 맞지 않는다.
- **파생 컬럼**: `d`, `m`, `day`, `전기요금(계절)`, `인건비`는 날짜·시간만으로 결정되어 새 정보가 없다.
